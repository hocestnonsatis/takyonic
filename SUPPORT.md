# Support

## Getting help

Before asking for help:

1. Read the [README](README.md) and
   [architecture guide](docs/ARCHITECTURE.md).
2. Search existing issues and discussions.
3. Confirm the problem still occurs on the latest release.

Use [GitHub Discussions][discussions] for setup questions, usage help, and
design conversations. Use the issue templates for reproducible bugs and focused
feature requests.

When asking for help, include the Takyonic version, operating system,
architecture, relevant configuration, reproduction steps, and sanitized logs.
Never include credentials or private data.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and report
them privately.

Takyonic is community-maintained, so response times are best effort.

[discussions]: https://github.com/hocestnonsatis/takyonic/discussions
